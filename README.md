# R1-A2-S5_DISE-O_SOLUCION

Se tiene un archivo train_data.csv de 1000 registros con el conjunto de datos de entrenamiento con información de niveles de obesidad en función de los hábitos alimenticios y la condición física, donde se contienen los siguiente 17 atributos:

Gender
Age
Height
Weight
family_history_with_overweight
FAVC
FCVC
NCP
CAEC
SMOKE
CH2O
SCC
FAF
TUE
CALC
MTRANS
NObeyesdad

A traves de un algoritmo usando tensorflow se requiere realice una predicción de riesgo de obesidad validando los datos de un archivo tests_data.csv y predecir la clase de NObeyesdad, en un archivo que se genera llamado resultado_predicion.csv donde se liste los 200 registros del archivo tets_data.csv agregando el dato de la clase NObeyesdad predicho por el modelo, posteriormente comparar los resultados de archivo resultado_predicion.csv con un archivo de control test_data_esperado.cvs que cuenta con la misma información de 200 registros ya clasificados con la clase NObeyesdad para cada registro, con el fin de mostrar el error de la predicción al comparar los datos de estos dos archivos el resultado_predicion.csv vs el test_data_esperado.cvs mostrar esta información de forma grafica
